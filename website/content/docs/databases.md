---
title: Databases and APIs
description: Map a live database schema or an OpenAPI definition next to your architecture.
---

**Connect database** reads the schema of PostgreSQL, MySQL, MariaDB, SQLite or SQL Server: tables, views, columns, keys and relationships. Enter the connection as fields or as a connection string. Only metadata is read, and the connection string stays in memory — it is never saved or logged.

The schema opens in a canvas where you can search, group tables and lay them out. Save it as [DBML](/docs/formats#dbml) to share it in the repository.

**Import OpenAPI** reads OpenAPI 3 or Swagger 2, in JSON or YAML, as a graph of operations and models.
