# Schematlas 0.4.0

- A new Leptos desktop interface with light and dark themes, rendered agent Markdown, and a clearer resizable chat panel.
- Smoother graph interactions, middle-mouse panning, keyboard selection and movement, and relationship ports that follow node placement.
- OpenAPI routes aligned with their request/response models, nested models in adjacent columns, shared models below, and sharp right-angle references. Choose **Auto layout** to apply the new arrangement to an existing saved map.
- Database connection forms with separate host, port, database, username, password, and TLS options, plus support for pasting connection strings. Improved MySQL connection handling.
- Compact agent tool responses, schema search, targeted entity descriptions, join-path discovery, statistics, sample rows, and query plans. SQL and HTTP execution remain subject to in-app approval.
- Local Claude Code CLI discovery and remembered agent selection.

Existing project files and saved manual graph positions are preserved.

Downloads are provided for macOS Apple Silicon and Intel, Windows x64, and Linux x64.
The release includes SHA256 checksums for all six installers. macOS downloads remain
ad-hoc signed and are not Apple-notarized; see the [macOS installation guide](../macos-releases.md).
